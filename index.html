Mestrado

IA multimodal para gestão de stress

No âmbito do Mestrado em Engenharia de Tecnologias e Sistemas Web, desenvolvo uma aplicação web e mobile para previsão personalizada de stress.

O sistema combina dados de wearables com inputs manuais do utilizador, utilizando IA para gerar recomendações adaptadas de alimentação, meditação e exercício físico.

  • Recolha multimodal de dados: sensores e autorreportagem.
  • Backend em FastAPI, com API documentada e integração de modelos.
  • Frontend web em React e aplicação mobile em React Native.
  • Foco em privacidade, usabilidade e experiência do utilizador.

Investigação

Segurança de dependências web

Desenvolvo também uma revisão sistemática de literatura sobre o impacto de dependências de terceiros inseguras na segurança de aplicações e servidores web.

Problema

Objetivo

Identificar estratégias eficazes de gestão, análise, atualização e mitigação de riscos em dependências.

Aplicação prática

Apoiar equipas de desenvolvimento na adoção de práticas mais seguras ao longo do ciclo de vida do software.
